Télécharger

LexOS 2.0.0 « Nomad »

L'édition Pro 2.0.0 est prête. Elle réunit tout : jouer aux jeux Windows (Steam/Proton, Lutris, Wine), le studio création (photo, musique, vidéo), Claude et Claude Code, les émulateurs, les manettes. Comme l'ISO fait plus de 2 Go, GitHub la livre en plusieurs morceaux dans une Release — le guide ci-dessous te tient par la main du téléchargement jusqu'au bureau, sans erreur.

▶ Essayer la démo interactive — téléchargement + démarrage, sans rien installer

⭐ Guide 100 % : télécharger et installer l'édition Pro

  1. Ouvrir la dernière ISO

    Clique ici : dernière ISO LexOS Pro. Ce lien pointe toujours vers la version la plus récente — chaque fois qu'on ajoute quelque chose, une nouvelle ISO s'y construit toute seule. Rien à retenir d'autre.

  2. Télécharger tous les morceaux

    Dans la section Assets, télécharge TOUS les fichiers …iso.part-00, …part-01, etc. ET le fichier …iso.sha256 — le tout dans un même dossier (par exemple ton dossier Téléchargements).

  3. Recoller les morceaux en une seule ISO

    Ouvre un terminal dans ce dossier et lance une seule commande :

    # Linux ou Mac
cat lexos-2.0.0-pro*.iso.part-* > lexos-2.0.0-pro-amd64.hybrid.iso
    # Windows (PowerShell, dans le dossier des morceaux)
cmd /c copy /b ((Get-ChildItem 'lexos-2.0.0-pro*.iso.part-*' | Sort-Object Name | ForEach-Object Name) -join '+') lexos-2.0.0-pro-amd64.hybrid.iso

  4. Vérifier que le fichier est intact

    sha256sum -c lexos-2.0.0-pro-amd64.hybrid.iso.sha256

    La réponse doit contenir « Réussi » / « OK ». Si ce n'est pas le cas, un morceau a mal été téléchargé — reprends l'étape 2.

  5. Graver l'ISO sur une clé USB

    Il te faut une clé de 8 Go ou plus (son contenu sera effacé). Sur téléphone Android : l'appli EtchDroid (gratuite) — voir la page Téléphone. Sur ordinateur : balenaEtcher (Windows/Mac/Linux) — choisis l'ISO recollée, choisis la clé, « Flash ».

  6. Démarrer sur la clé et installer

    Branche la clé, allume l'ordinateur en appuyant sur la touche de démarrage (souvent F12, F9, Échap ou F2) et choisis la clé USB. Au menu LexOS, choisis « Live system » : le bureau s'ouvre tout seul. Double-clique « Installer LexOS » et laisse-toi guider. Si on te demande un mot de passe, le compte de secours est lex / lex.

Rien n'est touché sur ton disque tant que tu ne lances pas toi-même l'installation : l'ISO démarre en session d'essai.

Tu préfères une autre saveur, ou construire l'ISO toi-même ? Les deux façons ci-dessous marchent aussi, gratuitement.

Aucune inscription, aucun compte, aucune donnée personnelle. Le dépôt est public, le code est sous licence MIT, et rien n'est envoyé nulle part pendant la construction ou l'utilisation de l'ISO.

Option A — la faire construire par GitHub (le plus simple)

Pas besoin d'installer quoi que ce soit sur ta machine.

  1. Ouvrir l'onglet Actions

    Sur la page du dépôt GitHub, onglet Actions → workflow « Construire l'ISO ».

  2. Lancer la construction

    Bouton Run workflow, choisis la saveur (voir le tableau plus bas), puis Run.

  3. Attendre environ une heure

    GitHub construit l'ISO de A à Z — même noyau, mêmes paquets, exactement ce que tu obtiendrais en la construisant toi-même.

  4. Récupérer le fichier

    Au bas de la page du job terminé, section Artifacts : lexos-<saveur>-iso. Conservé 14 jours.

Option B — la construire toi-même

Pour qui a déjà une machine Linux (Debian ou Ubuntu de préférence), 12 Go de disque libre et une connexion correcte — la construction télécharge plusieurs gigaoctets de paquets Debian.

sudo apt update
sudo apt install -y live-build debootstrap xorriso squashfs-tools \
                    rsync wget gnupg ca-certificates \
                    syslinux-common isolinux grub-efi-amd64-bin \
                    grub-pc-bin mtools dosfstools librsvg2-bin

git clone https://github.com/alexmarceauprevost812-source/logiciel-ti-lex-.git
cd logiciel-ti-lex-

make check      # contrôle que tous les outils sont là
make build      # construit l'ISO (saveur standard)
Pas envie d'installer Git ? Télécharge directement le code source en .zip, généré par GitHub — même contenu qu'un git clone, sans avoir besoin de Git installé. Dézippe, puis reprends à make check ci-dessus.
⬇ Code source (.zip)

Compte 20 à 60 minutes selon ta connexion. À la fin :

  ok  ISO      : lexos-1.0-standard-amd64.iso
  ok  Taille   : 2.4G
  ok  SHA-256  : lexos-1.0-standard-amd64.iso.sha256

Cinq saveurs

Choisis avant de construire — make build FLAVOUR=dev, ou directement make dev (idem pour minimal, standard, full, gaming).

SaveurContenuTaille approx.Commande
minimalConsole seule, aucun bureau~700 Miomake minimal
standardBureau XFCE, Firefox, dock, effets — défaut~2,5 Giomake standard
devstandard + compilateurs, langages, conteneurs, Neovim~4 Giomake dev
fulldev + LibreOffice, GIMP, Inkscape, VLC, Krita~6 Giomake full
gamingdev + Steam, Lutris, Wine, gamemode, MangoHud, Vulkan~5 Giomake gaming

Pas sûr laquelle prendre ? standard convient à la majorité des machines — les autres saveurs partent toutes de là et ajoutent.

Configuration requise

💾 Espace disque

Au moins 4 Go pour la clé USB (8 Go pour la saveur full). Prévoir 12 Go de libre sur la machine qui construit l'ISO.

🧠 Mémoire vive

2 Go minimum pour la saveur minimal, 4 Go recommandés pour les autres — machine réelle ou virtuelle.

🖥 Processeur

Tout processeur amd64 (64 bits) — LexOS ne construit pas d'image pour ARM à l'heure actuelle.

Vérifier l'intégrité du fichier

Chaque ISO construite est accompagnée d'une empreinte SHA-256. Avant de la graver, vérifie que le téléchargement n'a pas été corrompu :

sha256sum -c lexos-1.0-standard-amd64.iso.sha256

Si la réponse n'est pas OK, l'ISO est corrompue : recommence le téléchargement plutôt que de graver un fichier abîmé.

Aucune commande de ce projet n'efface ton disque dur sans confirmation explicite. L'ISO démarre en session démo par défaut — ton disque n'est touché que si tu lances toi-même lexos install-disk.
