Téléphone

LexOS sur un téléphone — ce qui est vrai, ce qui ne l'est pas

L'ISO LexOS est construite pour les processeurs Intel/AMD (x86_64) — ceux des ordinateurs. Un téléphone Android (Samsung S25 Ultra compris) tourne sur un processeur ARM, une architecture différente, derrière un démarrage verrouillé par le constructeur : l'ISO ne peut pas s'y installer, et aucun réglage ne change ça. Mais le téléphone a trois vrais rôles à jouer.

En résumé : le téléphone ne remplace pas le PC LexOS — il sert de démo de poche, d'outil d'installation, et de terminal Linux d'appoint. Les trois sont gratuits.

1 — La démo web, comme une app

Le bureau LexOS complet (fenêtres, terminal, paramètres, logithèque) tourne dans le navigateur du téléphone, sans rien installer.

  1. Ouvrir la démo

    Dans Chrome ou Samsung Internet, ouvre la démo web LexOS (le fichier web-demo/index.html du dépôt, ou le lien de démo que tu utilises déjà).

  2. L'épingler à l'écran d'accueil

    Menu ⋮ → « Ajouter à l'écran d'accueil ». Une icône LexOS apparaît, qui ouvre le bureau en plein écran, comme une application.

  3. Essayer le terminal

    Ouvre le Terminal de la démo et tape help — les commandes lexos accent, lexos dock, lexfetch répondent comme sur le vrai système.

2 — Le téléphone fabrique la clé USB d'installation

Pas besoin d'un deuxième ordinateur pour préparer la clé qui installera LexOS sur un PC : le téléphone s'en charge.

  1. Télécharger l'ISO sur le téléphone

    Depuis la page Télécharger (artefact GitHub, ~6,4 Go pour l'édition Pro — Wi-Fi recommandé). Dézippe le fichier .zip pour obtenir le .iso.

  2. Brancher une clé USB-C

    Une clé USB-C directe, ou une clé USB-A avec un adaptateur OTG. Minimum 8 Go — tout son contenu sera effacé.

  3. Flasher avec EtchDroid

    EtchDroid (Play Store, gratuit, sans root) : choisis « Écrire une image », prends le .iso, choisis la clé, confirme. Environ 10–20 minutes.

  4. Démarrer le PC avec la clé

    La suite est sur la page Installation — session démo d'abord, installation sur le disque seulement quand tu le décides.

3 — Les outils du terminal, directement sur le téléphone

Pour avoir un vrai Linux en ligne de commande dans la poche — pas la démo, pas une image : un Debian ARM complet, le même monde de paquets que LexOS.

  1. Installer Termux

    Depuis F-Droid (version recommandée) ou le Play Store. C'est un terminal Linux natif, sans root.

  2. Installer Debian dans Termux

    Dans Termux, tape :

    pkg update
pkg install proot-distro
proot-distro install debian
proot-distro login debian

    Te voilà dans un Debian trixie ARM — le même socle que LexOS. apt install fonctionne comme sur le vrai système.

  3. Retrouver les réflexes LexOS

    Les outils du terminal LexOS sont des scripts bash du dépôt (config/includes.chroot/usr/bin/) : plusieurs fonctionnent tels quels dans ce Debian. Par exemple, copier lexfetch dans /usr/local/bin et le lancer.

Honnêteté d'architecte : ce Debian dans Termux est un vrai Linux, mais en ARM et sans le bureau LexOS — pas de dock, pas d'effets TV 1980, pas de saveur Pro (Steam/Proton exigent un PC x86_64). Pour l'expérience complète, c'est l'ISO sur un ordinateur.
