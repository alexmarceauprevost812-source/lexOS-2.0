    Tester une clé USB

    Ce test écrit sur le périphérique choisi : se tromper de cible efface des données, donc il ne se lance pas depuis un clic. Repérez d'abord la clé (lsblk), puis dans un terminal :

    f3write /media/VOTRE-CLE && f3read /media/VOTRE-CLE

    Nécessite le paquet f3 (déjà dans 59-diagnostic.list).
